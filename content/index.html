Simple code. Strong guarantees.

Zore is a natively compiled language with ownership-based memory safety, explicit errors, and deterministic resource cleanup.

Early alpha · v0.1.0-alpha.1Early development. The compiler supports a growing subset; compatibility is not stable.

Memory safety by design

Ownership and borrowing make resource lifetimes explicit. No garbage collector.

One model for concurrency

Async/await, tasks, and channels follow ordinary ownership rules. Explore concurrency.

Familiar, readable syntax

Errors are values. Handle them explicitly or propagate with ?, preserving deterministic cleanup.

Built in the open

An open-source alpha with public specification and conformance evidence. See current boundaries.

Get to know the language.

A few clear rules connect the code you write to the program that runs.

01 / OWNERSHIP

Borrow by default.

Plain parameters borrow. Use mut for mutable borrowing and own to transfer ownership. Function signatures tell you what they need.
