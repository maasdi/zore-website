Zore/Documentation

Introduction

A small starting point for a native language built around ownership, explicit errors, and deterministic cleanup.

Early alpha · v0.1.0-alpha.1. The Rust bootstrap compiler supports a growing subset. Compatibility is not stable; start with small programs and read the current boundaries.

Start with a program

You can check and format source with the published compiler alone. To turn source into a native executable, you also need Rust, clang, and your host linker. The installation guide covers both paths.

  1. Install the alpha

    Choose a host archive, verify its checksum, and prepare the native toolchain.

  2. Run your first program

    Create a complete project, check it, and print Hello, Zore! from a native executable.

  3. Learn the language model

    Read about borrowed parameters, Copy and Move values, errors, and concurrent work.

  4. Work with tools and packages

    Format source, run application tests, and keep dependencies reproducible.

Who this alpha is for

Zore is for developers who want to evaluate the supported language, inspect its design, and report concrete problems. Expect evolving syntax, APIs, diagnostics, and platform behavior. This release does not declare stable compatibility or complete MVP conformance.

Tutorials and reference

These pages explain a practical path through the pinned alpha. The language specification is authoritative for language rules. Detailed package APIs and compiler evidence remain in the release-pinned upstream repository.
