Zore/Documentation/Install Zore

Install Zore

Use a published compiler archive. There is no compiler source checkout or compiler build step.

Choose your path. zore check and zore fmt work without a native toolchain. Native build, run, and application test need Rust 1.98.1, clang with LLVM 15 or newer, and the host linker. The Linux builder image includes these tools.

1. Choose your host archive

All downloads below belong to v0.1.0-alpha.1. These are native host builds; they do not cross-compile to other targets.

HostArchive targetDownload
Linux x64, glibc 2.39+; tested on Ubuntu 24.04x86_64-unknown-linux-gnuArchive · SHA-256
Apple Silicon, macOS 15+aarch64-apple-darwinArchive · SHA-256
Intel Mac, macOS 15+x86_64-apple-darwinArchive · SHA-256
Windows x64, MSVCx86_64-pc-windows-msvcArchive · SHA-256

Linux musl, Linux ARM, Windows ARM/GNU, and older host versions are not validated release artifacts. Each archive contains the compiler, its license, and artifact.json with version, target, source commit, toolchain, and binary-checksum provenance. Keep that manifest with your download.

2. Verify and install

Obtain the archive and checksum from the same trusted GitHub release. A checksum verifies transfer integrity. Do not run an archive whose checksum differs.

Linux x64

Run these commands in a new working directory. Add the installation directory to your shell’s startup configuration if you want the PATH change to persist.

set -eu
zore_version=0.1.0-alpha.1
archive="zore-${zore_version}-x86_64-unknown-linux-gnu.tar.gz"
base="https://github.com/maasdi/zore/releases/download/v${zore_version}"
curl -fLO "$base/$archive"
curl -fLO "$base/$archive.sha256"
sha256sum -c "$archive.sha256"
mkdir -p "$HOME/.local/bin" zore-alpha
tar -xzf "$archive" -C zore-alpha
install -m 0755 zore-alpha/zore "$HOME/.local/bin/zore"
export PATH="$HOME/.local/bin:$PATH"
zore --version

macOS 15 or newer

Use aarch64-apple-darwin for Apple Silicon or x86_64-apple-darwin for Intel. This example selects Apple Silicon; change only target for Intel.

set -eu
target=aarch64-apple-darwin
archive="zore-0.1.0-alpha.1-${target}.tar.gz"
base="https://github.com/maasdi/zore/releases/download/v0.1.0-alpha.1"
curl -fLO "$base/$archive"
curl -fLO "$base/$archive.sha256"
shasum -a 256 -c "$archive.sha256"
mkdir -p "$HOME/.local/bin" zore-alpha
tar -xzf "$archive" -C zore-alpha
install -m 0755 zore-alpha/zore "$HOME/.local/bin/zore"
export PATH="$HOME/.local/bin:$PATH"
zore --version

Windows x64

Run in PowerShell. The script stops if the downloaded checksum does not match. It adds the extracted directory to PATH for this session; add the same directory to your user PATH for later sessions.

$archive = "zore-0.1.0-alpha.1-x86_64-pc-windows-msvc.zip"
$base = "https://github.com/maasdi/zore/releases/download/v0.1.0-alpha.1"
Invoke-WebRequest "$base/$archive" -OutFile $archive
Invoke-WebRequest "$base/$archive.sha256" -OutFile "$archive.sha256"
$expectedHash = ((Get-Content "$archive.sha256" -Raw).Trim() -split '\s+')[0]
$actualHash = (Get-FileHash $archive -Algorithm SHA256).Hash
if ($actualHash -ne $expectedHash) { throw "Checksum mismatch" }
Expand-Archive -LiteralPath $archive -DestinationPath zore-alpha
$compilerDirectory = (Resolve-Path zore-alpha).Path
$env:PATH = "$compilerDirectory;$env:PATH"
zore --version

Every platform should report:

zore 0.1.0-alpha.1

3. Set up native builds

To build, run, or execute application tests, install Rust through rustup and the tested 1.98.1 toolchain. In your project directory, select it with a directory override:

rustup toolchain install 1.98.1
rustup override set 1.98.1
rustc --version
clang --version
  • Ubuntu 24.04: install clang and host build tools with sudo apt-get install clang build-essential.
  • macOS: install Xcode Command Line Tools with xcode-select --install. Verify that clang reports LLVM 15 or newer.
  • Windows: install Visual Studio C++ Build Tools with the Windows SDK and LLVM clang 15 or newer. Build from an x64 Developer PowerShell or Developer Command Prompt so the MSVC linker and SDK are available.

The compiler invokes rustc to compile and link its bundled runtime. Set ZORE_RUSTC and ZORE_CC to full executable paths when selecting a particular Rust compiler or clang. These variables take an executable, not a shell command.

Alternative: the Linux builder image

Docker can provide the complete Linux amd64 toolchain. The published image contains the prebuilt compiler, Rust 1.98.1, clang, and host dependencies on Ubuntu 24.04. Use this exact digest:

docker run --rm --platform linux/amd64 \
  ghcr.io/maasdi/zore-builder@sha256:0d61df24b24405ff9a99a0b4bcd25bf603b1c907d70f35ade6204b502a8a7bb1 \
  zore --version

From your Hello project directory, mount it at /workspace and run the program. This POSIX-shell example needs Docker; the complete project is on the next page.

docker run --rm --platform linux/amd64 \
  -v "$PWD:/workspace" -w /workspace \
  ghcr.io/maasdi/zore-builder@sha256:0d61df24b24405ff9a99a0b4bcd25bf603b1c907d70f35ade6204b502a8a7bb1 \
  zore run main.ore
If the registry is unavailable

Download the release’s builder-image archive and checksum. Verify, then load it locally:

set -eu
sha256sum -c zore-builder-0.1.0-alpha.1-linux-amd64.tar.gz.sha256
gzip -dc zore-builder-0.1.0-alpha.1-linux-amd64.tar.gz | docker load
docker run --rm --platform linux/amd64 \
  ghcr.io/maasdi/zore-builder:0.1.0-alpha.1 zore --version

Troubleshooting

  • Compiler not found: check the install directory is on PATH; try the compiler’s full path.
  • glibc version error: the Linux archive needs glibc 2.39 or newer. Use a supported host or the builder image.
  • Checking works, running fails: confirm Rust 1.98.1, clang 15+, and the host linker are available in the same shell.
  • Windows linker error: use the x64 developer shell and ensure link.exe resolves to MSVC. Another tool’s executable with the same name can shadow it.
  • Wrong version: inspect PATH for an older compiler, and verify the archive’s manifest and checksum.

For platform behavior, consult the pinned platform guide. The alpha distribution reference records the original packaging instructions.
