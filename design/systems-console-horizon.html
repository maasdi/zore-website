Memory safety by design

Ownership and borrowing make resource lifetimes explicit. No garbage collector.

One model for concurrency

Async/await, tasks, and channels follow ordinary ownership rules.

Familiar, readable syntax

Clear function signatures, explicit errors, and less ceremony between you and your code.

Built in the open

An open-source language in early development. Follow along, experiment, and contribute.

A little less to keep in your head

Get to know the language.

A few clear rules connect the code you write to the program that runs.

01 / OWNERSHIP

Borrow by default.

Plain parameters borrow. Use mut for mutable borrowing and own to transfer ownership. Function signatures tell you what they need.

Read the language specification
02 / NATIVE TOOLS

From source to a program.

Check and format without a native toolchain. Build, run, and test with Rust, clang, and your platform’s linker.

Set up the alpha
