# Approved website design: Systems Console with Horizon

Approved on 2026-10-29. Use this concept as the visual baseline for the standalone Zore website.

- [Interactive mockup](systems-console-horizon.html)
- [Desktop preview](systems-console-horizon.png)
- [Mobile preview](systems-console-horizon-mobile.png)
- [Documentation preview](systems-console-horizon-docs.png)
- [Original supplied reference](zore_concept.png)

The identity uses a warm sun over a fine horizon as the O in a geometric ZORE wordmark. The website combines a dark navy hero and source panel with indigo actions and lighter reading surfaces. Preserve the confirmed tagline, honest alpha status and published-alpha installation flow.
